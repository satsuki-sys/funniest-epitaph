## What it does

`main.py` writes one line of famous last words — a tombstone epitaph of
at most 150 characters — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## The epitaph

> I always said I'd sleep when I'm dead. I was right.
